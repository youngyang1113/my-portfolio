# 项目图片目录

将你的项目截图放在此目录下，然后在 `Projects.jsx` 和 `Home.jsx` 中使用本地路径。

## 使用方法

1. 将图片文件（如 `project1.jpg`）放在此目录
2. 在代码中使用路径：`/images/project1.jpg`

## 示例

```javascript
{
  id: 1,
  title: '项目名称',
  image: '/images/project1.jpg',  // 本地图片路径
  // ...
}
```

## 推荐图片尺寸

- 宽度：800px
- 高度：600px
- 格式：JPG、PNG、WebP

## 当前使用的在线图片

目前项目使用 Unsplash 在线图片，你可以替换为本地图片以获得更好的性能。
